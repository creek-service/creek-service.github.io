Creek v0.5.0 is available on [Maven Central](https://central.sonatype.com/search?q=org.creekservice),
with its Gradle plugins on the [Plugin Portal](https://plugins.gradle.org/search?term=org.creekservice).
This minor release marks the move from the alpha preview to a more complete beta release.

The [v0.4.4 release](/releases/2026/04/28/v0.4.4-released.html) introduced basic JSON Schema
serialization for Kafka. v0.5.0 builds on that foundation, completing the JSON Schema support.

### Highlights

- **More flexible JSON system tests:** Kafka now supports
  [pluggable system-test serde providers](https://github.com/creek-service/creek-kafka/pull/909)
  and separates Schema Registry-specific functionality into a
  [dedicated `schema-store` module](https://github.com/creek-service/creek-kafka/pull/910).
- **Seed data before startup:** System tests can
  [seed inputs before the services under test start](https://github.com/creek-service/creek-system-test/pull/768),
  with an [`afterSeeding` callback](https://github.com/creek-service/creek-system-test/pull/771)
  for work that must happen after seeding.
- **Improved JSON Schema tooling:** Schema generation now supports
  [`OptionalLong`, `OptionalInt` and `OptionalDouble`](https://github.com/creek-service/creek-json-schema/pull/615).
  The JSON Schema Gradle plugin also
  [regenerates deleted schema files](https://github.com/creek-service/creek-json-schema-gradle-plugin/pull/480)
  when compilation is otherwise up to date.

### Upgrading

The Kafka [`streams-test` types are deprecated](https://github.com/creek-service/creek-kafka/pull/912).
Projects using them should plan to move to the supported test-extension APIs.
As with v0.4.4, Java 17 is the minimum supported Java version.

For the complete list of changes, see the v0.5.0 release notes for
[Kafka](https://github.com/creek-service/creek-kafka/releases/tag/v0.5.0),
[JSON Schema](https://github.com/creek-service/creek-json-schema/releases/tag/v0.5.0),
[the JSON Schema Gradle plugin](https://github.com/creek-service/creek-json-schema-gradle-plugin/releases/tag/v0.5.0),
and [system testing](https://github.com/creek-service/creek-system-test/releases/tag/v0.5.0).
